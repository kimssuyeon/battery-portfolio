# BATTERY Portfolio

최신 포트폴리오 + UNFOLD + PRINT NOTES 전체 파일입니다.

## GitHub 업로드
1. ZIP을 압축 해제합니다.
2. 이 폴더 안의 index.html, assets, previews, projects를 모두 저장소 최상위에 올립니다.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.

index.html은 저장소 첫 화면에 있어야 합니다. ZIP 자체를 업로드하지 마세요.
UNFOLD와 인쇄 노트 버튼은 함께 포함된 projects 폴더의 사이트로 연결됩니다.

## 이미지 수정
assets 폴더에서 해당 이미지를 같은 파일명으로 교체하면 됩니다.
이미지의 가로세로 비율을 유지하세요.
